# Лабораторная работа №3. Оценка числа π методом Монте-Карло

Программа оценивает число π по доле случайных точек, попавших внутрь четверти единичного круга:

```text
π ≈ 4 · Nвнутри / Nвсего
```

Для каждой точки независимо генерируются координаты `x` и `y` на квадрате `[0, 1] × [0, 1]`. Точка считается попавшей в круг, если выполняется условие `x² + y² ≤ 1`.

## Ход эксперимента

Программа выполняет 100 независимых экспериментов. В каждом из них число точек увеличивается с шагом 2 000 до максимума 200 000, пока абсолютная ошибка оценки не станет меньше `0.009`. Фиксированный seed `228` делает результат воспроизводимым.

После завершения выводятся:

- время выполнения;
- доля экспериментов, достигших заданной точности;
- медианное и среднее число точек;
- теоретическая оценка требуемого числа испытаний.

## Запуск

Работа использует только стандартную библиотеку Python:

```powershell
cd 4ModLab3
python main.py
```

Параметры `total_trials`, `max_points`, `step`, `eps` и seed задаются в функции `main`.
