# Лабораторная работа №1. Игра «Жизнь»

Реализация двумерного клеточного автомата Джона Конвея с настраиваемыми правилами рождения и выживания клеток.

## Возможности

- поле произвольного размера;
- замкнутые границы в форме тора или фиксированные мёртвые границы;
- правила в формате B/S, например B3/S23;
- случайное начальное заполнение с фиксированным seed;
- вставка готовых фигур: глайдера и пушки Госпера;
- вывод в консоль и анимация Matplotlib;
- сохранение результата в GIF.

На каждом шаге программа подсчитывает восемь соседей каждой клетки. Мёртвая клетка рождается при числе соседей из правила `B`, а живая сохраняется при числе соседей из правила `S`.

## Запуск

```powershell
cd 4ModLab1
pip install numpy matplotlib pillow
python main.py
```

Текущая демонстрация создаёт поле 200×200, применяет правила B3678/S34678, заполняет 40% клеток и сохраняет 1000 кадров в `game_of_life.gif`.

Основные параметры находятся в функции `main`: размер поля, правила `rule_b` и `rule_s`, плотность заполнения `p`, число кадров, интервал и имя GIF. Чтобы только показать анимацию без сохранения, передайте `save=False` в метод `animate` и вызовите `plt.show()` в подходящем окружении.

## Файлы

- `main.py` — модель, шаблоны фигур и демонстрационный запуск;
- `game_of_life*.gif` — сохранённые результаты для трёх наборов правил.
