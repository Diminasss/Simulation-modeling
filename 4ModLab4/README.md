# Лабораторная работа №4. Пуассоновский и эрланговский потоки

Генерация интервалов между событиями для пуассоновского и эрланговского потоков. Работа сравнивает собственные алгоритмы со встроенными генераторами NumPy.

## Реализация

- пуассоновский поток моделируется экспоненциальными интервалами;
- собственный экспоненциальный генератор использует метод обратной функции;
- эрланговский интервал строится как сумма `k` независимых экспоненциальных величин;
- NumPy-вариант Эрланга использует гамма-распределение;
- для каждой выборки рассчитываются среднее, дисперсия, СКО и коэффициент вариации;
- результаты сравниваются в консоли и на совмещённых гистограммах.

Параметризация обеих реализаций согласована так, чтобы математическое ожидание интервала было равно `1 / λ`.

## Запуск

```powershell
cd 4ModLab4
pip install -r requirements.txt
python main.py
```

В демонстрационном запуске генерируются 5 000 интервалов при интенсивности `λ = 3` и порядке Эрланга `k = 3`. Эти значения задаются в нижней части `main.py`.

## Файлы

- `main.py` — генераторы потоков, метрики и визуализация;
- `requirements.txt` — зависимости;
- `results/` — гистограммы сравнения.
